System Architecture
Full RAG pipeline — from PDF upload to the answer (Ollama or Sarvam AI, text or voice)
Ingestion Pipeline
1. PDF Upload
Flask receives file → saved to uploads/
2. Text Extraction — PyMuPDF
Fast native text extraction per page
3. OCR Fallback — RapidOCR / PaddleOCR
Scanned/image pages → rendered and OCR'd in the background
4. Table Extraction — PyMuPDF
Structured tables → Markdown representation
5. Image Extraction — PyMuPDF + OCR
Embedded images extracted → OCR'd for text
6. Structure + Chunking
Directory entries and FAQ pairs kept whole; other text in overlapping chunks
7. Embedding — BAAI/bge-small-en-v1.5
384-dim dense vectors, normalised for cosine
8. FAISS Index — IndexFlatIP
Inner-product search, persisted to disk
RAG Query Pipeline
1. User Query — typed or spoken
Voice → Sarvam Saarika speech-to-text; non-English questions translated to English for search
2. Hybrid Retrieval — FAISS + BM25
Dense and keyword search fused with RRF
3. Re-ranking — cross-encoder
Short list re-scored; top chunks kept
4. Prompt Assembly
System prompt + context chunks + question (+ answer-language rule)
5. LLM — Ollama (Llama 3.2 3B) or Sarvam AI
Grounded answer, in the selected Indian language when Sarvam is used
6. Text-to-speech — Sarvam Bulbul
Spoken answer in the selected language
7. Log → chat_history.txt
Q, A, and source citations persisted
